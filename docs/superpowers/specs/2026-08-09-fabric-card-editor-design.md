# Fabric.js 会员证编辑器设计

## 1. 背景与目标

当前项目使用 Vue 3、Vue Konva 和 Konva 绘制一代、二代会员证。会员证成品本身具有明确视觉风格，但编辑流程依赖独立表单、抽象的头像位置滑杆和遮挡预览的浮层，降低了制作效率。

本次方向是将渲染与交互层迁移到 Fabric.js，构建一个固定模板会员证编辑器。桌面端的核心目标是让实时预览和控制台始终同屏；移动端则在保留实时预览的前提下提供直接触摸操作。

这份文档只定义已确认的产品与技术方案，不授权或包含具体实现。

## 2. 第一版范围

第一版实现固定模板编辑器：

- 保留一代、二代会员证模板。
- 头像支持画布内拖动、等比缩放和手机双指捏合。
- 姓名、英文名、乐队名和生日支持画布内直接编辑。
- 保留控制台字段，用于键盘输入和精确调整。
- 保留恢复默认、复制图片和高分辨率 PNG 导出。
- 背景、Logo、字段标签和免责声明等模板元素锁定且不可选中。
- 一代和二代共用编辑器架构，只使用不同模板配置。

第一版明确不包含：

- 自由新增、删除或旋转文字和图片。
- 自由图层排序。
- 模板设计器。
- 完整撤销和重做历史。
- 云端保存、账号同步或分享服务。
- 自动草稿保存。

## 3. 核心交互

采用“画布快速操作，控制台精确调整”的双通道模型。两个入口操作同一份会员证数据。

### 3.1 头像

- 点击头像后显示选中边框和缩放手柄。
- 鼠标或触摸拖动头像调整位置。
- 桌面端使用控制柄或滚轮等比缩放。
- 手机端使用双指捏合等比缩放。
- 禁止旋转、翻转和非等比缩放。
- 拖动和缩放必须保证头像始终覆盖裁切区域，不得出现空白。
- 双击头像或点击控制台按钮可恢复默认裁切。
- 控制台同步显示头像缩放、水平位置和垂直位置。

### 3.2 文字

- 姓名、英文名、乐队名和生日使用 Fabric.js `IText`。
- 点击或双击可编辑文字，固定字段不能被拖动、缩放或旋转。
- 画布输入实时同步到控制台，控制台输入也实时同步到画布。
- Escape 取消当前编辑并恢复本次编辑前的字段值。
- 长文本先动态缩小字号；达到最小字号仍无法容纳时显示字段错误，不静默溢出或裁切。

### 3.3 固定对象与导出状态

- 背景、Logo、标签和免责声明不可选中，也不响应指针事件。
- 同一时间只突出当前编辑对象，避免画布出现多组控制框。
- 导出前结束文字编辑、清除活动选区并校验资源状态。
- 编辑光标、选框、控制柄和辅助提示不得进入导出图片。

## 4. 响应式布局

### 4.1 桌面端

桌面端使用固定双栏工作台：

```text
┌──────────────────────────────────────┬──────────────────────┐
│ 顶栏：模板切换 / 恢复默认             │                      │
├──────────────────────────────────────┤ 编辑控制台            │
│                                      │ 基本信息              │
│          Fabric.js 画布               │ 姓名 / 英文名          │
│                                      │ 乐队名称 / 生日         │
│      头像可拖动、文字可直接编辑        │                      │
│                                      │ 头像精确调整           │
│                                      │ 缩放 / X / Y          │
│                                      ├──────────────────────┤
│                                      │ [复制] [导出图片]      │
└──────────────────────────────────────┴──────────────────────┘
```

- 画布区约占可用宽度的 65%，控制台约占 35%。
- 画布在可用空间内尽量放大并保持会员证比例。
- 控制台独立滚动，导出操作固定在控制台底部。
- 一代和二代切换位于顶栏，并通过 Vue Router 保留 `/` 与 `/old` 地址。
- 工作区设定合理最大宽度，避免在超宽显示器上过度拉伸。
- 工作区使用安静的中性色，使会员证保持视觉主导地位。

### 4.2 手机端

手机端使用“固定预览 + 分组控制台 + 固定导出栏”：

```text
┌──────────────────────────┐
│ [一代] [二代]      [重置] │
├──────────────────────────┤
│      Fabric.js 预览       │
│   拖动头像 / 捏合缩放      │
├──────────────────────────┤
│ [基本信息] [头像调整]      │
├──────────────────────────┤
│ 当前分组的编辑控件         │
├──────────────────────────┤
│ [复制图片]   [导出图片]    │
└──────────────────────────┘
```

- 预览保留约三分之一可用高度，并始终可见。
- 点击预览可进入全屏查看模式。
- 控件按“基本信息”和“头像调整”分组，避免一次展示全部选项。
- 触摸控制柄不小于 44×44 CSS 像素，并处理底部安全区。
- 手机横屏和小型平板在空间允许时切换为双栏结构。
- 只有发生在画布上的拖动和捏合才阻止页面滚动。

## 5. 数据与渲染架构

### 5.1 唯一业务数据源

Fabric.js 对象是可变的交互视图，不直接作为应用业务数据源。编辑器维护独立的 `CardDocument`：

```ts
interface CardDocument {
  templateId: "current" | "legacy";
  name: string;
  nameEn: string;
  bandName: string;
  birthday?: string;
  avatar: {
    src: string;
    x: number;
    y: number;
    scale: number;
  };
}
```

数据流为：

```text
Vue 控制台 / Fabric 交互
              ↓
        CardDocument
              ↓
      Fabric 渲染适配层
        ↙            ↘
交互 Canvas       导出 StaticCanvas
```

- 画布事件更新 `CardDocument`。
- Vue 控制台更新 `CardDocument`。
- 渲染适配层把状态同步到 Fabric 对象。
- 同步需要标记更新来源，防止画布事件和 Vue watcher 相互触发形成循环。

### 5.2 坐标系统

- 模板内部坐标固定为 960×640。
- 页面尺寸变化只调整视口显示比例，不修改模板对象坐标。
- 桌面、手机和导出共用同一套模板坐标。
- 头像位置与缩放保存为模板坐标，避免不同视口之间产生漂移。

### 5.3 Fabric 对象权限

| 对象 | Fabric 类型 | 权限 |
|---|---|---|
| 背景 | `FabricImage` | 锁定、不可选中 |
| Logo | `FabricImage` | 锁定、不可选中 |
| 标签与免责声明 | `FabricText` | 锁定、不可选中 |
| 姓名等字段 | `IText` | 可编辑，不可移动或变形 |
| 头像 | `FabricImage` + `clipPath` | 可移动、等比缩放，不可旋转 |
| 头像裁切边界 | `Rect` | 锁定，仅提供视觉边界 |

### 5.4 导出架构

- 交互画布仅用于预览和编辑。
- 导出时创建离屏 `StaticCanvas`，使用同一模板渲染器和 `CardDocument` 重新绘制。
- PNG 输出使用 4 倍倍率，最终尺寸为 3840×2560。
- 离屏渲染完成或失败后必须销毁临时画布和资源引用。
- Vue 组件卸载时调用 Fabric Canvas 的异步 `dispose()` 清理事件和 DOM。

## 6. 组件与模块边界

建议结构：

```text
src/
├── components/editor/
│   ├── FabricCardCanvas.vue
│   ├── CardInspector.vue
│   ├── CardToolbar.vue
│   └── ExportActions.vue
├── composables/
│   └── useCardEditor.ts
├── fabric/
│   ├── createEditorCanvas.ts
│   ├── renderCardDocument.ts
│   ├── bindEditorEvents.ts
│   └── exportCard.ts
└── templates/
    ├── currentCardTemplate.ts
    └── legacyCardTemplate.ts
```

- `CardEditorView` 负责页面结构和模板路由。
- `FabricCardCanvas` 只负责 Canvas 生命周期、视口和事件桥接。
- `CardInspector` 只编辑 `CardDocument`，不直接操作 Fabric 对象。
- `renderCardDocument` 同时服务交互画布与离屏导出。
- 模板文件定义固定对象、坐标、默认内容、字体约束和头像裁切区域。

## 7. 加载、错误与恢复

### 7.1 初始化

初始化顺序为：模板配置、字体、背景与 Logo、示例头像、Fabric 对象。全部完成前显示与会员证等比例的骨架预览，并禁用复制与导出。

字体加载失败时使用明确的系统字体回退，不要求用户刷新页面。

### 7.2 图片上传

- 接受 JPG、PNG 和 WebP，第一版文件上限为 10 MB。
- 图片加载成功后按覆盖裁切框的方式计算初始缩放并居中。
- 图片加载失败时保留原头像和当前编辑状态。
- 错误信息必须包含可执行的下一步。

### 7.3 导出与剪贴板

- 导出前校验字段、字体和图片资源状态。
- 导出进行中禁止重复提交。
- Clipboard API 不可用或权限被拒绝时，保留保存图片作为明确回退。
- 成功、失败和加载状态通过可见提示与 `aria-live` 同步反馈。

### 7.4 恢复范围

第一版只提供：

- 恢复头像默认裁切。
- 恢复单个字段默认值。
- 恢复整张会员证默认内容。
- 在可能丢失内容的模板切换前确认。

第一版不实现完整撤销和重做。

## 8. 迁移策略

采用并行迁移，Fabric.js 达到功能和视觉一致后才删除 Konva：

1. 建立 `CardDocument` 和模板配置。
2. 用 Fabric.js 静态复刻二代会员证。
3. 与现有 Konva 输出进行视觉对比。
4. 加入头像拖动、缩放和裁切约束。
5. 加入 `IText` 直接编辑和控制台同步。
6. 复刻一代会员证。
7. 完成桌面双栏和手机布局。
8. 完成离屏导出、复制和错误反馈。
9. 完成两代模板验收。
10. 替换正式路由并删除 Konva、Vue Konva 和重复旧组件。

迁移期间保留现有实现作为视觉和功能基准。新实现先使用内部开发入口，不直接替换正式路由。

## 9. 测试策略

### 9.1 单元测试

- 模板默认值与字段差异。
- 头像初始覆盖缩放计算。
- 拖动和缩放边界计算。
- 长文本字号适配与错误条件。
- `CardDocument` 字段重置和整卡重置。
- 模板切换保护。
- 导出尺寸和倍率计算。

### 9.2 组件测试

- 控制台输入同步到 Fabric 对象。
- Fabric 文字编辑同步回控制台。
- 选中头像时显示正确控制项。
- 固定对象不可选中。
- 导出中按钮禁用。
- 成功和错误状态可被辅助技术读取。

### 9.3 浏览器测试

- 桌面 1440×1000、手机竖屏 390×844 和手机横屏。
- `/` 与 `/old` 两条路由。
- 鼠标拖动、滚轮缩放、触摸拖动和双指缩放。
- 键盘文字编辑和 Escape 取消。
- PNG 下载、剪贴板成功与失败回退。
- 无横向溢出，控制台不遮挡预览。

## 10. 第一版验收标准

- 桌面端预览与控制台始终同屏。
- 头像可直接拖动和等比缩放，且不会露出裁切空白。
- 画布文字可直接编辑，并与控制台双向同步。
- 两代模板均能正确加载和生成。
- 固定元素不会被误选或移动。
- 移动端可以拖动和捏合头像。
- 导出 PNG 为 3840×2560，且不包含编辑辅助元素。
- 复制失败时提供保存图片的明确回退。
- 长文本不会无提示地溢出会员证。
- 构建、类型检查、单元测试和主要浏览器流程全部通过。
- Fabric.js 版本通过验收后才移除 Konva。

## 11. 技术依据

设计依赖 Fabric.js 官方当前文档中稳定公开的能力：交互式 `Canvas`、`FabricImage`、`IText`、对象控制柄、`clipPath`、图片导出和 Canvas 销毁。实施计划将固定当时的稳定 npm 版本和 lockfile，不使用未公开的内部 API。

- https://fabricjs.com/docs/core-concepts/
- https://fabricjs.com/api/classes/canvas/
- https://fabricjs.com/api/classes/fabricimage/
- https://fabricjs.com/docs/events/
